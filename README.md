# 🩺 RadAssist AI: Preliminary X-Ray Screener

RadAssist AI is an educational, AI-powered triage support tool designed to assist general practitioners in under-resourced and rural healthcare clinics where radiologist access is limited.

## 📋 Features
- Upload digital chest or bone X-ray scans.
- Uses Gemini 2.5 Flash multimodal vision capabilities to analyze visual features.
- Generates structured preliminary triage notes highlighting areas of interest and suggested urgency levels.
- Designed with built-in Responsible AI warnings and clinical disclaimers.

## 🛠️ Tech Stack
- **Frontend / UI:** Streamlit (Python)
- **AI Model:** Google Gemini 2.5 Flash API
- **Image Processing:** Pillow (PIL)

## ⚠️ Medical Disclaimer
RadAssist AI provides preliminary visual observations for educational and triage assistance only. It is not an autonomous diagnostic device and does not replace evaluation by a certified radiologist.
